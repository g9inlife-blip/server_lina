## 2026-10-01 18:10 추가: KCPTube 경로 확정 (외부 분석 결과)

### 핵심 결과
실제 응답은 **KCPTube 경로**임이 확정:
```
KCPTube.Send
   ↓
KCPTube.Update
   ↓
KCPTube.TryRead (ret=1)
   ↓
Decrypt
   ↓
Deserialize<object>
   ↓
OpInfo
   ↓
DataCenter.ProccessRequestRes
```
- TCPTube.TryRead는 계속 ret=0 (TCP 아님)

### OpCode=2 응답 내용
메인화면 데이터의 상당 부분이 하나의 OpInfo에 포함:
- User, Heros, Items, Weapons, Equiments
- Chapters, Sections, Teams, Fashions
- Quests, Charges, Activities...

특히:
- Items: Dictionary<int, ProtoItem>
- Weapons: Dictionary<int, ProtoWeapon>
- Equiments: Dictionary<string, ProtoEquipment>
- Chapters: Dictionary<int, ProtoChapter>
- Sections: Dictionary<int, ProtoSection>

### Ghidra 확인
**KCPTube.Send:**
```
ProtoBuf.Serializer.Serialize<object>
→ EncryptUnSafe
→ KCP.Send
```

**KCPTube.TryRead:**
```
KCP 수신
→ DecryptUnSafe
→ DecompressUnSafe  ← 중요!
→ ProtoBuf.Serializer.Deserialize<object>
→ response 반환
```

### 중요 발견: DecompressUnSafe
